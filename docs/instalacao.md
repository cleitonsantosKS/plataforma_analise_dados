# Guia de Instalação - Plataforma de Análise de Dados

## 📥 Instruções de Setup

Siga os passos abaixo para configurar o ambiente e rodar o projeto localmente do zero.

### 1. Clonar o Repositório
```bash
git clone git@github.com:cleitonsantosKS/plataforma_analise_dados.git
cd plataforma_analise_dados
```

### 2. Configurar o Ambiente de Execução
### Criação do Ambiente Virtual\n```bash\npython -m venv venv\nsource venv/bin/activate\n```\n\n### Instalação de dependências\n```bash\npip install -r requirements.txt\n```

### 3. Verificar Instalação
Inicie a aplicação e valide se todas as rotas e componentes básicos carregam perfeitamente na porta `8000`.
